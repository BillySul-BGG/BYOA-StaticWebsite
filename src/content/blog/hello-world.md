# Hello World!

Welcome to my first blog post. This is an example of how to write blog posts using markdown.

## Features

- **Markdown Support**: Write your posts in markdown format
- **Front Matter**: Add metadata like title and date at the top
- **Code Highlighting**: Share code snippets easily

```javascript
console.log("Hello, World!");
```

## How to Add a New Post

1. Create a new `.md` file in the `src/content/blog` directory
2. Add front matter at the top with title and date
3. Write your content in markdown
4. The build system will automatically convert it to HTML

That's it! The post will automatically appear in the blog section of your site.
